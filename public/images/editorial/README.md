# Ana sayfa oda görselleri

Yerleşik image_gen aracıyla oluşturulan konsept görselleridir; gerçek ürün fotoğrafları değildir. Ana sayfada konsept açıklamasıyla kullanılır. Gerçek katalog fotoğrafları `public/images/products` klasöründedir.

- `montessori-dream.webp`: Ana sayfa açılış görseli.
- `nursery-sunlight.webp`: Marka hikâyesi görseli.
- Aynı isimli PNG dosyaları yüksek çözünürlüklü kaynaklardır. WebP sürümleri sharp ile kalite 85 kullanılarak hazırlanmıştır.
